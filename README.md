# Zeri-MS-Tracker
An application that tracks your movespeed in league of legends, displaying your peak in fight MS originally designed for marksman like Zeri.
The UI Sits next to the Crit Chance Stat in an attempt to blend in with its fellow champion stats
The top button shrinks the menu and hides any developer values. This currently isn't fully working as the home-guards heavily dilute the Peak movespeed and its anti-home-guard system isn't perfected yet.
